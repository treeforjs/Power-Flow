# Preserved session helpers and verification evidence

This folder preserves authored reproduction/audit scripts and the actual
pre-push test evidence that previously lived outside Git. The scripts retain
their original run-directory assumptions; they are review/reproduction helpers,
not additional production entry points or unreviewed physical models.

The current source, finished delivery packages and unfinished physical-input
requirements are committed together. See
[the verification note](../docs/prepush_verification_20261028.md) for passing
checks and unresolved failures. No all-tests-passing claim is made.

Compiled binaries, build caches, bytecode and large regenerable simulation
packet files remain excluded. The delivery archives retain their selected
inputs, checksums, plots and replay instructions.
