# Publication assembly and verification

The supporting-document assembly copies 24 historical archives exactly and
creates one explicitly labelled publication derivative omitting compiled Python
cache files. It preserves all project-authored reports and generated verification
figures in those packages, their baseline requirements, source versions and
failure/repair records. No numerical model or prior scientific suite is replayed
by this assembly.

The [independent publication readback](verification.json) checks copied archive
bytes, the derivative's retained members and omissions, document copies,
checksums, relative links and the unfinished-work labels. The
[assembly record](assembly_record.json) pins the completed catalog.

[Production-MHD retirement evidence](mhd_retirement/README.md) includes its
focused tests, source/AST preservation and read-only review. The first metadata
copy attempt used an incorrect command-name selector; its source/log are retained
alongside the corrected exact-command/hash binding. No test was repeated for
that copying repair.

The command snapshot is a complete-record prefix from before final publication.
Later verification, commits, pushes and completion append to the local journal;
they cannot be embedded recursively in the commit they record. Historical
application and review scripts retain their original workspace paths and are
evidence, rather than an installation workflow.

The first publication readback found an omitted catalog pin for an existing
query-only discovery record. The [metadata amendment](discovery_record_pin_amendment.json)
adds its exact identity and refreshes the assembly binding. The initial report
and focused continuation retain the failure and correction; successful archive
checks were preserved without repeating their readback.
