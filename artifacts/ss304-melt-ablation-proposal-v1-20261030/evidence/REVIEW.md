# Focused component review

The final source passes 74 focused manufactured checks in both a normal and an
undefined-behavior-sanitized build. Three compile-time assertions check private
proposal construction and const inventory/evidence access. Both builds used the
same complete source identity and emitted byte-identical `tests.json` files.

The separate Python implementation reconstructs exact positive weight sums,
source count and mass debits, bound-reference changes, weighted R/I/K, incremental
trigger costs, cumulative local allowance, total energy and mass closure, support
momentum, retained oxide exposure and candidate temperature projections. It uses
Fraction arithmetic and an independent 90-digit Decimal proper-velocity energy
calculation. It passed 349 checks per output plus one deterministic comparison,
699 total. Eleven proposal receipts and three exact budget-refusal receipts are
included. This is an independent arithmetic implementation, not an independent
physical validation or native birth/integration review.

Review found an overflow risk in a floating comparison used to check proposed K
against proper velocity. The final implementation compares exact represented
differences against an exact eight-epsilon operand bound, avoiding an infinite
floating tolerance. Proposals were also made opaque with const accessors before
the final verification, and named extra-energy receivers are retained in the
receipt. No existing sealed implementation or tolerance was changed.

The first `normal-001` run contains 66 preliminary checks before these interface
and extra test changes. It is retained as history, not the qualified final source.
`normal-002` and `ubsan-001` are the authoritative matching final-source runs.
The sanitizer used `-fsanitize=undefined -fno-sanitize-recover=all`; both compiles
used strict floating flags and warnings as errors. Each compile/run lease lasted
under six seconds, with CPU7, nice15, fixed one-thread environment, frozen
compiler/runtime, a real exclusive `testing-core7.lock` and bounded subprocesses.
No GPU work, production signal, full integration or physical-time advance took
place. Production identity and stopped/frozen state were checked before and
after each run.

The remaining limits are deliberate and material: caller-admitted immutable
callbacks; a shared local condensed temperature; one explicitly separated thermal
and bound-reference convention; lossless Count2-compatible source projection;
neutral identity-preserving proposed products; and stationary support. Real foil
layer inputs, product registry/source kinetics, changing geometry/current, actual
native products, common atomic commit and restart remain unqualified. The
component contract lists those obligations. No new defect was found in the
reused material or exact-count headers, which were checked byte-for-byte against
their pinned inputs rather than retested with broad suites.
