2. Neutral stream rule (replaces API-v1.txt 3.3)
  Input: the source quote D (ReleaseQuote released: the expected release of the step, one
  binary64 value), its log, the exact accepted stock Owner::inventory(patch), the clock.
   refuse D with more than one positive carrier (typed debit-representation);
   D = 0: no leaves, no draw;
   x = fl(d / w0) for d the binary64 value of D; refuse x above the per-stream cap
   (typed macroparticle-cap, log scope log D - log w0);
   n = SR(x): floor(x) + Bernoulli(x - floor(x)), the exact Bernoulli of philox_core.h on
   the count stream key (run seed, step, stream id, candidate 0, purpose 1);
   stock cap: n is reduced to the largest m <= n with m w0 <= stock (exact count
   comparison); the decision flag "merged" records this cap (v1.1 meaning: capped at the
   exact stock); no leaf has another weight;
   leaves: n leaves of weight exactly w0; leaf k carries the six neutral marks of
   (run seed, step, stream id, k, purpose 3) for the source v6 release law (velocity,
   position, release time);
   debit = n w0 exactly (ExactParticleCount credited n times with w0).
  The source v6 quantized mode (SourceSettings::quantized_neutral_weight = w0) debits its
  exact stock by exactly the leaves' sum n w0 and keeps the remainder; it refuses a leaf of
  any other weight and a debit above the exact stock (typed stock_drain).
  Unbiasedness: E[n] = x exactly for the binary64 x (stochastic rounding), so E[n w0] = D up
  to the one division rounding of x (<= 2^-53 relative). Stock, released molecules and
  carriers satisfy  stock_after + sum(n) w0 = stock_before  exactly, and carriers created =
  released molecules / w0 exactly.
  Purpose tags: the count draw uses purpose 1 on candidate 0 (as for electron streams; the
  stream id separates them); the per-leaf marks use purpose 3 with candidate = leaf index,
  as in v1. A count draw keyed with purpose 3 would reuse the mark words of leaf 0, so the
  count keeps purpose 1.
  Compared with v1 (floor rule, >= 1 leaf per active patch and step, leaves partitioning D
  exactly): v1 creates one resident neutral carrier per active patch per step whatever the
  release; v1.1 creates on average D/w0 carriers per step and releases n w0 molecules.

3. Default w0_neutral = 1e6 molecules per neutral packet (per-stream configuration; choose it per
  run from the expected surface temperatures). Basis (growth measurement below; oxide-water
  Temkin/Eyring patch, coverage 0.33, one Hall-slice patch of 5 mm x 6.25 mm, 1.34e14 molecules,
  dt = 10 fs): mean release 5.2 molecules/step at 300 K, 7.9e3 at 400 K, 1.3e7 at 600 K. With
  w0 = 1e6 a patch creates ~0.5 carriers/ns at 300 K and ~8e2/ns at 400 K, so a 1-2 ns pilot stays below the
  1e5 resident-carrier cap (30 patches at 400 K: ~5e4 carriers over 2 ns; at 300 K: ~30) while
  every released molecule is accounted exactly (the v1 floor rule creates 1e5 carriers/ns per active patch at
  any temperature). One packet is 1e6 molecules, 1.25e17 m^-3 in one (200 um)^3 volume (about 0.5 mPa at
  300 K), the same macro-weight as the electrons of the Hall v3 multistep run. Above ~450 K the
  release rises steeply (600 K: 1.3e6 carriers/ns per patch at w0 = 1e6); hot-surface runs need
  w0 ~ 1e8 or larger, chosen as (expected release over the window x patches) / carrier budget.
