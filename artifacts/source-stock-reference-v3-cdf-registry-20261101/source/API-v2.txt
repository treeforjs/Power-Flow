Source/reference adapter v2 — explicit coordinate domains and genuine SurfaceBirth

Namespace source_stock_reference_v2. Depends on separately qualified Source
v7.3 and native v8.7, unchanged blob v3.1.1. Legacy source v7.2 / adapter v1
remain sealed. Source v7.3 supplies immutable SurfaceBirth tokens in a Trial.
Existing ElectronLink canonical ID names either an actual source Candidate +

complete; native BirthScope::prepare is called once by the adapter itself.

Strong types: LocalThermalPoint, GlobalFieldPoint, NativePoint each carry V value.
native_neutral_face_point(owner, patch, LocalThermalPoint{packet.x}) translates
local neutral z by the declared slice center.
native_surface_point(owner, patch, GlobalFieldPoint{birth.origin_m()}) retains
already-global z exactly. field_point(NativePoint) applies the same native to
field shift used by native geometry. The normal face snap tolerance remains
1e-12 m and is checked, never an arbitrary face relocation.

Native birth origin text is source-v7.3/surface/<token content SHA>. Its exact
phase space is the sealed origin + declared displacement, packet proper
velocity, actual declared mass, birth time and common end minus birth time.
A positive matching distance requires bridge=true and exact bridge_start_m
at the surface. Zero distance requires bridge=false and a zero unused bridge
start. Returned/internal/wall/phase paths remain refused. Retarding electrons
use explicit source policy return_extent_m=0 and ordinary first-hit motion.

PreparedReferenceTransfer::surface_transfers() exposes immutable rows with
source port/patch/native ID, actual source token hash, native packet ID, global
field origin, declared displacement, native origin and matching point, charge,
wall heat, electron work-function reference, matching field work and bridge flag.
These are separate ownership operands, not additional heat loads. Genuine
native receipt bridges are verified against the actual translated endpoints
and charge after BirthScope::prepare. Parent must deposit those bridges once
and verify computed E.J against matching work with existing field-work guards.
The adapter does not publish, deposit currents, change weights, reheat the
foil, alter stock or replace kinetic evolution.
