Current protocol gaps that must be resolved first:

  binding, commit/abort, restart codec or exactly-once stage protocol.
- Native receipt.records_root commits all raw stage records. Inventory refusal
  truncates events per carrier; admitted-only events cannot reproduce that root.
  Add an admitted-event commitment/mask while retaining the raw-stage commitment.
- FlowRecord has no packet/native ID. Add stable debit identity and actual
  before/remainder weights, velocities and carried internal energy. Check these
  against the native debit plan; native alone performs the count debit.
- Bind accepted native/gas digests, stage/order, trial field/target snapshot and
  post-feedback target hash. The same snapshot must govern both MCC majorant and
  sampled targets on CPU and device paths.
- Own both chemistry stages in the same trial; publish native and gas states
  atomically. Failed native validation, discarded transport trials, duplicate
  take and restore must leave accepted gas state/RNG unchanged.
- Preserve exact count/P/K accounting. Consuming reaction correction is actual
  debited-target moments minus sampled-target moments; GAS return uses outgoing
  minus sampled moments and has no count debit. Release transfers must close
  with the conservative actual-parcel reservoir. No compensating count debit.
- Owner realizability guards must reject negative thermal variance, and zero
  count must retain/resolve or refuse nonzero momentum/energy; clamping is not
  accepted as closure. Current owner is unfinished and requires its own tests.

record/debit export and an independent exact closure validator, with feedback
still disabled and strict production refusal retained. Exercise full/partial
consumption, GAS return, actual parcel release, two stages, abort/retry, forged
