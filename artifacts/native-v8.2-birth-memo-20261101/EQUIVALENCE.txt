Host schema-v8 birth validation memo: review rationale

This successor changes only the host branch at the end of FullTimeAccess::births.
The pre-existing device branch and the schema-v5 host path are unchanged. The
shared numerical source preimage is recorded in SUCCESSOR-BASE.json; the exact
change is in birth-memo.diff. No chemistry, particle motion or field arithmetic
changes. The public API, checkpoint schema, frozen inputs and target-owner guard
are unchanged. Archive/source identities differ; source-bound anchor and
checkpoint provenance must be compared separately from physical bytes. Before
an anchor, some accepted/history hashes can remain identical across releases.

The optimization applies only if the exact immutable base has a validation memo
for the same cap. The memo retains packet payload, ever-ID payload and NativeRows
storage and compares exact cap plus rows.same_as, so pointer reuse cannot forge
proof. FullTimeAccess::live and the scope/frame/binding checks still run first.
When no matching memo exists, the full census validator still runs.

The birth constructor proves the postconditions of full_time_census for the
append before marking validation: state registration and species binding;
positive finite binary64 weight and exact single-carrier ArenaCount; guarded
finite x/u through closed_position or emitting-surface validation; canonical new
packet IDs and contiguous increasing native IDs; no duplicate ever/packet IDs;
source-credit exact equality; carrier cap before allocation; one-carrier packet
ownership; and unique insertion of matching packet-key-index entries. The base
rows and packets are immutable. Returned births append no carrier; wall births
retain their existing previous-sink parent, identical weight/hit-point and ID
checks. Stage B exercises bridge, returned, wall, internal-energy and merge paths.
The memo is an internal proof cache, not accepted physical state or RNG state.

Qualification plan: inherited CPU/refusal/restart suites; Stage B host and device;
GPU lifetime/flows/chemistry; and a bounded populated actual-archive differential
fixture with binary64-bit physical records, exact count/charge/kinetic ledger operands,
RNG/history, accepted state unchanged after invalid/stale/scope/cap refusals.
Provenance-bound release hashes are reported separately, never described as equal.
Timers measure birth prepare and complete manufactured step; SMT sibling load is
recorded and contaminated timing cannot support a speed claim. This is a
zero-field/zero-event fixture, not a full-physics runtime prediction.

Coverage boundaries: the populated actual-archive differential uses ordinary
source births and sinks. Wall/returned/bridge/internal-energy/merge variants are
covered separately by Stage B controls. The changed-cap differential control
checks early carrier-cap refusal and accepted-state preservation; it does not
instrument memo hit/miss branches or prove an accepted changed-cap fallback.

Status: qualification pending. No production performance or plasma claim.
