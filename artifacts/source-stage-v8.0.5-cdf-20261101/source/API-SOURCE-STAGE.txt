Native-v8 SourceStage API (qualification in progress)

Namespace powerflow::source_stage_v8 in source/source_stage_v8.hpp.
Port is factory-only: bind_port(actual shared Hall, SliceSource, SourceOptions,
actual native options, chemistry config, exact patch/stream registrations).
It retains that Hall object's exact thermal slice, actual registry/config/blob
identity, source owner and reference adapter. Equal-content replacement is not
authority. SourceSet/OwnerSet contains ports, exact shared arrival policy and
arrival owner.

PreparedSourceStage::prepare takes accepted source state roots, accepted arrival
root and native source seal, actual common step and live native BirthScope, and
an explicit zero-return-extent BirthPolicy. It owns real source trials, immutable
complete native birth credit and authentic PreparedBirths, source thermal loads,
and an allocated PreparedCommit for arrival. Every trial leaves accepted owners
unchanged. Dropping it is rollback; retry uses the unchanged arrival bases/marks.

The current implementation uses fixed patch-centre spatial quadrature, accepted
patch-mean temperature and accepted-start Hall field. It does not sample a new
birth position after exposure. Source v7.4 uses the actual registry kinetic mass
and immutable declared-mass cache. All neutral chemical-reference transfer is
count-for-count inventory loss versus birth gain; no offset enters thermal heat.

source_after_sha256 is an acyclic transition commitment used by the native birth
receipt. It is not the vector of final source state hashes. prepare_publication
requires all accepted owners unchanged, exact future Hall clock/configuration and
actual per-birth bridge work closure. It allocates future source state hashes,
arrival hash and publication receipt before any owner publishes. Root must also
preflight the actual Hall proposal with its authentic native census/candidate,
then preflight native/gas and hold the common critical section. After Hall moves,
publish_sources_prevalidated swaps the already-prepared source and arrival state
without allocation. It must never be called as an independent publication path.

Mandatory coupling gates:
- Accepted-start source field need not match final Hall midpoint bridge E.J.
  Existing work guard refuses mismatch. prepare_against_proposal snapshots only an actual owner-preflighted prior
  proposal midpoint with exact common binding. Root must iterate/retry until the
  unchanged work guard passes; never compensate mismatch in heat.
- Gas conductor correction E/P/U is separate from native incident K/internal.
  Root must transfer it to Hall heat exactly once or a qualified pending store.
- Work-function electron reservoir bookkeeping is distinct from native electron
  chemical reference (zero) and neutral chemical stock references.
- SourceStage does not own gas, chemistry, phase expansion or native motion.
- Retained micro-layers, wall/photo/phase/metal/writeoff/nonzero-internal paths
  remain explicit refusals. Multi-enhancement-class electron patches refuse
  until class/arrival partitioning is implemented.
- Registry/blob70fcc2ad... only. New chemistry blob adoption requires explicit
  source/reference admission revision; no mass or reference-energy coercion.

Component fixtures are manufactured finite-stock cases at the supported C19
drive start. Their water births do not establish a populated electron plasma,
onset time, physical convergence or a full60ns result.

prepare_against_proposal(owners, accepted, common, BirthScope, prior proposal,
prior actual census, BirthPolicy, intervals={}) is read-only on accepted owners.
The actual retained Hall must preflight that proposal/census and its common clock
must match. No caller arrays are accepted. Arrival and chemistry run_seed must
match exactly. Identical accepted arrival bases keep the same counter/marks;
changed physical emission expectation can legitimately change the birth count.
The native four-fork cap remains in force; root must abandon/recreate an outer
at the accepted state if more attempts are needed.
