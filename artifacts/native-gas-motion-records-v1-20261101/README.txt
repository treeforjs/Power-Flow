Checked native-to-gas motion records, v1 (2026-11-01)

This pure converter checks full before/source-start/after inventories and actual
birth/sink data before producing gas birth/sink flows and carrier-share movers.
It never grants live native/gas publication authority. Integration must obtain
its View from the exact authenticated native prepared-motion token and recheck
that token before any candidate mutation. That integration is outstanding.

CPU548 and ASan/UBSan552 each pass64 controls. The adapter and gas owner were
rebuilt with sanitizers; the separately pinned native library was not rebuilt.
Fixtures use manufactured population/flow data, the actual gas owner, and the
actual native internal-energy encoder. They cover source/cell/sink partition,
incident rather than initial sink momentum, exact stored internal energy,
input permutation, exact gas deposit plus exit closure and nonempty gas restore.
The native source/field solve is not exercised by these converter controls.

Important observed transport limitation: actual gas v1.6 carrier_shares leaves
nonzero correction stock in an emptied origin cell (both final runs report1).
Total deposit plus all exits closes exactly, but this does not qualify spatial
feedback or physical integration. Also, gas wall/* currently combines conductor
and exterior correction losses; retaining the native sink label alone cannot
split that exact correction afterward. A separate census-conservative gas
successor is being implemented; do not open the common transport gate here.

The existing carrier-share model instantaneously mixes same-species cell
correction among the post-birth census, including newborns. It is not an
individual particle's retained recoil history. No full water breakdown, complete
network, physical convergence, GPU mapping or runtime improvement is claimed.

Explicit refusals: unreported births/sinks, changed species/weight/packet,
invalid native mass/charge/phase space, malformed sink metadata, unsupported
merge/split and returned/wall-response births, or ambiguous stored internal
energy on multi-carrier packets. Never weaken these to pass integration.
