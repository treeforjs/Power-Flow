Conditional frozen-electron collisionality/resolution assessment

assess.py reads the original 26.478443519 ns midpoint particle/reference fields,
the exact prior host-only face probes, the sealed spatial diagnostic, strict
gas-phase H2O observable tables, and the identified source-v2 oxide scenario.
No PIC object, field solve, source reservoir, reaction, trajectory, or production
process is advanced. A direct existing C++ observational query checks numerical
support/threshold/gap semantics and Python arithmetic on representative points.
This is a static assessment, not a new collision implementation for the arena.

All rates use actual electron weights, kinetic energies and relativistic speeds
against explicitly stationary ground-state H2O test targets. Gas temperature
sets ideal-gas density; target thermal velocities are not convolved. Unsupported
population weight stays in denominators and is reported; missing rate weight
cannot be determined without missing cross sections. Channels overlap and are
never summed. Momentum transfer and ion yields are not exclusive event counts.
Only total-scattering sigma permits the stated single-scattering attenuation
interpretation under the declared straight/frozen test assumptions. Other
1-exp(-tau_observable) values are formal comparison scales only. A mathematically
covered valence BEB formula is not an experimentally validated full mechanism.

The assumed all-H2O background is distinct from a finite desorbed column. RGA
does not fix composition or electrode coverage. Source-v2 columns explicitly
select the ideal Fe2O3-like oxide, theta0, released fraction and thickness; they
are not inferred neutral history in the electron-only fixture. Source-law rows
are pointwise frozen-start hypotheses, not a reservoir integration. Positive
remaining fractions are retained even when released fraction rounds to one.
Effusive speed illustrations assume neutral mass18.0106u; no actual runtime gas
catalog mass exists in this legacy fixture. Flight durations are illustrative,
not inferred birth ages.

Local Eparallel/Eperp and gyro scales use recorded original E/B. Ideal cold
crossed-field and Hull formulas require uniform static planar E perpendicular B;
they do not constrain a hot finite-edge Eparallel trajectory. Debye scales use
explicit Maxwellian proxies/scenarios, with nonneutral, anisotropic, finite
population and weak-coupling limitations. No shielding is imposed. Neither
dx/rho nor an ionization energy-gain length alone is a field-mesh error criterion.
Target overlap, field gradients, boundary conditions and the resolved collision
volume still require independent controls. No unique halo diagnosis is made.

Run reproduction under the existing frozen runtime and shared CPU7 lease using
run.sh with a fresh output directory. No build, download or dependency update.
Output REPORT.txt and handoff distinguish qualified static arithmetic/support
checks from every unqualified physical/evolving/full-mechanism claim.
