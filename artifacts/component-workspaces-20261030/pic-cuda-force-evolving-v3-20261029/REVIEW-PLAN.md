This is an unqualified isolated candidate for one 1 ps evolving saved-state
replay. No GPU test has been executed by its preparer. The CMake build flag is
OFF by default; enabling it builds a dedicated benchmark executable, not a
deployment target. The executable additionally requires parent CPU7/nice15/one
thread, an explicit bounded-replay token, the exact late seed clock/step and at
most 1 ps. Outputs must resolve inside this prefix's qualification-runs. No
production resume, automatic mode selection, promotion or deployment is allowed.

The accepted v2 core, its mandatory-reference API, all reviewed artifacts,
captured actual midpoint, PTX and original application sources remain unchanged.
This prefix copies the precise math unchanged. A separately named
CudaForceRuntime forks only the backend API/static snapshot contract and output
validation: no independent oracle is an argument to runtime evaluate. All v2
context selection, retained reference, fences, stream resources, drain/fallback,
quarantine, error-reporting and transactional commit code is retained.

The three explicit modes are off (default native original loop), shadow and
optimized candidate. Shadow executes the original callback/Boris sequence into
a fresh independent immutable E/B/u reference, applies all original finite,
componentwise and weighted reference tolerances, and commits only after those
gates pass. Optimized candidate uses the runtime executor without calculating
that additional independent reference. This is a new unqualified execution
policy for isolated comparison; it is not a modification of v2's reference
requirement or a deployment approval.

All modes retain the original input geometry/particle checks, source sampling,
reservoirs, seeds, native and voltage extrapolation checks, gyro/plasma/source/
displacement timestep rules, both half-drifts, both charge depositions and
guarded field solves, absorption, path-integrated edge transfers, clock update,
field/kinetic energy and charge/Gauss/continuity ledger accounting and the
original two-million-particle guard. Runtime validates finite E/B/u/status and
proper-velocity norm, kinetic energy, weighted energy/momentum finiteness, shape,
capacity, q/m, positive mass/weight, input finiteness/domain, owner thread/context
and unchanged particle metadata before velocity-only transactional mutation.
Weighted oracle agreement remains an additional shadow gate. No physical guard
or tolerance is removed to create an optimized measurement.

The typed provider deliberately calls the unchanged original Fields::set and
Voltage::at at exactly start+(ledger.time_s+.5*dt). It retains their epsilon,
upper_bound/clamp and original clock expressions. Shared math retains x/y-.0045,
native nonuniform bins, native B replacing uniform B, native inductive Ez and
the symmetric unit-psi axial correction. Self phi is the actual recovered field
from the first solve at its step-boundary conductor potential; only native and
axial terms use the selected midpoint voltage. It is never replaced by that
voltage or inferred from an old checkpoint.

Registration is one explicit target GapPic pointer, owning host thread and
immutable mode/provider per process. Unit/topology epochs are explicitly1 for
this frozen mesh/unit solution; any change rejects. Native frame IDs are the
actual original current/current+1 indices with their exact times. Native frame
changes explicitly re-export/validate/upload the selected data. Self phi is
copied fresh each force. Fixed capacity65,536, at most256 accepted steps and a
2 GiB full-state trace per run bound the investigation; overflow disqualifies
rather than changing the timestep, sampling or physics.

After half drift, zero particles means no kick: no midpoint provider or callback
call, no force allocation/launch, and both original drifts/solves still occur.
Any kick/reference/runtime failure poisons the session and exits the candidate
process after cleanup reporting; there is no retry, native fallback or half-step
checkpoint save. Every accepted-step trace is emitted only after the second
solve, clock update and original application finite-ledger guard. It includes
every raw particle, recovered phi, both edge-transfer arrays, complete raw
diagnostics and all source-reservoir spans/integrals/weighted temperatures.
Original final checkpoints, reservoir metadata, density frames and histories
remain available for the established full saved-state comparison policy.
