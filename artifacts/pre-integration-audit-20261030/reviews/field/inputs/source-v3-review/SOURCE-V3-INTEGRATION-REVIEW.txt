Required native and root interfaces

1. Native source admission is absent from the current contract.
   MOTION-RECEIPT-SCHEMA.txt explicitly requires empty source/boundary arrays.
   prepare_canonical_motion rejects active IDs and every boundary hit; its
   coverage is all_native_carriers_no_sources_no_boundaries. Passing v3 JSON
   through the existing optional arrays cannot create a valid source operation.
   The native owner must define a separately versioned typed admission before
   Hall extends the proposal. Source-after must then be the actual candidate
   source-state hash, replacing the present inactive-source operand only in
   that new contract. The resident envelope and census seal stay unchanged.

2. Root must supply a real count/RNG/ID/layer owner.
   prepare_patch exports both binary64 expected_number and log_expected_number
   with availability/underflow flags. Zero scalar with finite log is retained.
   BirthSample requires positive representable weight, fixed draws, physical
   birth policy/time, event and canonical IDs, exact exposure_key, revision,
   base hash and staged count token. v3 preflight checks field/heat identity; it
   does not authenticate the external token or establish sampling accuracy.
   Native IDs, Count2 limbs, packet parts and equal packet kinematics must come
   from that owner. Multiple representable weights need its exact sum proof;
   neither a hi+lo conversion nor independent duplicate layers is implied here.
   No accumulator, floor, threshold, statistical law or birth-time rule is
   chosen by this review. QualificationOnly never enters production admission.

3. The source handoff needs the independent kinetic policy.
   axial_trial_field.hpp::handoff_remainder calls axial::push for end-tau.
   axial_particles.hpp::intersection uses field side/zmin/zmax and its older
   short rectangle. The canonical policy instead uses native width/gap,
   short/feed planes and the inner-gap bridge. Extra field width or axial air
   padding therefore changes the old handoff boundary but not the native one.
   A path can pass the native feed plane before the old mover reports any hit.
   Until a qualified partial-flight operation binds kinetic_policy_sha256,
   reject such source/handoff paths. Do not accept the padded-field endpoint,
   relabel the old surface ID, or clip position while retaining a longer-flight
   momentum, current or work receipt. A boundary-capable extension must solve
   the actual partial flight with the unchanged native force kernel, retain
   authoritative common-dt deposition and full-common gyro guards, and return
   the exact native first-hit sink, outward normal, time, charge and kinetic
   energy. Source-layer paths also need finite-target admission, not merely
   an endpoint-inside-field check. Root/native own removal and sink ledgers.

4. Thermal patch ownership must be made explicit in a new aggregate port.
   Thermal::make_owners constructs zero patches and keeps its Couplers private.
   v3 prepare_patch needs a reference to the actual accepted Coupler and its
   exact Epoch. A future Hall aggregate must construct admitted patch maps and
   provide controlled read-only accepted-owner access, without a second owner.
   Each mapping binds body, axial slice, local patch, positive source-state ID,
   global origin, slice center/height, normal, thermal mesh/material identities,
   held-temperature choice and regime admissions. Area fractions must partition
   the actual patch once. Height equals Geometry.height; local neutral z gains
   the slice center once; source relative vectors keep their Cartesian axes.
   Use prepare_heat once per Coupler with that slice's actual Joule coefficient,
   all certified Qwall candidates and other admitted transfers. Two separate
   Joule/source preparations would compete for the same accepted thermal base.

5. Root must settle source eligibility in the two collision exposures.
   V3 fixes physical birth and handoff times but does not define the parent
   SSA's eligibility or duration for newborn, Active, HandedOff or removed IDs.
   The current closed C/2-motion-C/2 coordinator has only resident populations.
   Native and parent owners must provide the explicit membership/time contract
   for both exposures and its temporal qualification. This review does not
   choose a newborn collision duration or apply ordinary resident exposure by
   default. It is an integration gate, not a claim of a source-kernel defect.

Hall proposal composition once those interfaces are sealed

For each bounded nonlinear iteration, construct one immutable AxialTrialField
from the actual midpoint E/B and pass the same token to mapped source work.
Keep accepted heat at begin, explicitly held, while field time is begin+dt/2;
layer current_time and birth time remain physical times. Existing Hall exact
rounded-midpoint convergence must hold for the same arrays used by all sources,
ordinary motion, remainders and Maxwell work. Keep the actual array comparison
and SHA256 binding; the adapter's values_fingerprint is a field-identity check,
not authentication of an external owner or substitute for proposal sealing.

Import PrecisionPath displacement computed from relative endpoints before
adding global origin. Preserve zero-duration quantum paths, already weighted
charge/work and common-dt deposition. Do not use the v2 absolute-endpoint
subtraction importer, multiply weight/height again, or divide by flight time.
Build total current from ordinary motion, source paths and handoff remainder
exactly once. Source identity is Qwall+dK+dRef_e+dImage=Wfield; heat receives
only Qwall. Keep signed reference/image and boundary/circuit energy in their
owners. The present ordinary-motion/Joule-only combined balance must be
extended with those actual terms; diagnostic mean heat and handoff kinetic
increment cannot become extra wall heat or a post hoc energy correction.

Reject a stale owner, foreign trial, unresolved path, duplicate current/heat,
unbound sampling rule, missed kinetic hit or failed global guard by discarding
the entire proposal. Restart records only accepted native population, source
layers/origins/mapping, field, thermal state, count/RNG state and all watermarks
under one root checkpoint. Do not serialize Candidate pointers or field tokens;
rebuild trial fields from the accepted checkpoint. V2 layer/heat byte parity
alone does not establish cross-owner crash consistency.
