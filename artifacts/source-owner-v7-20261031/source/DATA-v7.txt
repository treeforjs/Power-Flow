Heat/source owner v7 -- surface parameter data, tags and citations -- 2026-10-31

The parameter values live in one place, native/mfem_electrode_heat_source_v7/surface_data_v7.hpp, entered through
surface_v7::Registry::use(name, value, low, high, unit, tag, source, location, note). The full registry (every
row with band, tag, source id, location and note) is written by test_surface_v7 to
  OUT/<label>/run-*/normal-test_surface_v7/parameters-v7.json
and checked there (tag, source, location present; band contains the value; names unique). This file gives the
source ids, the access level of each source, and the bounded/open items. No value was taken from a source that
was not read at the stated access level; figure readings are marked "fig" with their reading error.

Tags
  measured        value measured on the stated material/surface (or read from a published figure, marked fig)
  recommended     fitted/recommended value of the cited compilation or model paper, used as published
  model_derived   derived here or in the source from cited quantities by a stated relation
  scenario        no measurement exists for this foil; a declared scenario value with a sensitivity band
  benchmark       the v6.1 benchmark value (selectable; not a property of the foil)

Access levels: FT full text read; ABS abstract read; SEC value seen in a secondary source citing the primary;
FIG value read from a published figure.
