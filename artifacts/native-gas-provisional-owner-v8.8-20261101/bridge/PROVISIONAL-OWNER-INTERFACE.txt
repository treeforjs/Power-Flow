Proposed explicit native/gas strict admission (not implemented)

Current strict tracked-target guard remains closed. The diagnostic fixture and
its public JSON/accounting helpers never authorize publication.

1. Concrete bridge capability, not serialized evidence

Add an opaque native ProvisionalTargetPermit with no public data constructor.
Only the pinned concrete native_gas_common::CoupledTrial bridge may request one
through a private native friend/access factory. The native factory binds the
actual CollisionScope identity/generation, immutable before snapshot, full outer
lifetime and configured bridge-contract hash. A permit is move-only and consumed
once before chemistry runs, including a failed attempt. A deterministic retry
requires a fresh live permit. A flag/string/JSON or user-subclass callback cannot
create the capability through the public API.

The concrete bridge itself owns the real gas Owner shared lifetime, GasStepScope
exact rollback attempt, the native outer, registry/blob bindings and private
candidate revision. It never exposes a raw authorization constructor or generic
closure-passed callback. Bridge contract identity pins the actual native, gas,
chemistry and bridge code/configuration, not only a claimed label.

2. Quarantined candidate preparation

A separate CollisionScope preparation overload accepts the one-shot permit and
actual host target Provider. It may calculate the same guarded eventful candidate
while diagnostic_field_target_approximation stays false, but the resulting token
is quarantined: can_publish/try_publish return false and outer sealing cannot use
it. All existing network, coverage, event, resource and catalogue guards remain.
Only the permit-scoped guarded calculation bypasses the specific 'no target
energy owner supplied' refusal; no global configuration boolean bypass exists.

Actual candidate population and stock accessors may inspect this quarantined
token using a separate live-inspection predicate; they must not equate inspection
with publication. Current published CPU diagnostics keep their existing API.

3. Concrete exact closure and live stage witness

The bridge validates authentic pre-MCC feedback, actual admitted export and
actual before/after carrier/parcel/packet-U inventories, applies only the admitted
records/debits/releases to the real gas candidate, and checks exact charge/nuclei,
energy/momentum plus independently derived chemical-reference operands. Native
actual pending parcel K/P must equal the gas mirror; no event-only surrogate.
The existing actual-reference/process-Q conversion ledger remains explicit and
must independently match actual stoichiometry, not be an arbitrary observed
residual. Nonzero/unsupported ownership, coverage or realizability refuses the
entire common trial. Charged-target correction currently remains a moment/ledger
approximation and must not be relabelled as a kinetic target update.

A private bridge-produced StageWitness retains the real gas shared owner and
post-take CandidateBinding. Native authorization verifies the permit/native
candidate identities and binds the exact proof roots. Subsequent native stage
publication requires a nonallocating/noexcept preflight of that actual live gas
binding. Witness construction is restricted to the concrete bridge; a private
function pointer/context is acceptable only if no public arbitrary callback
factory exists. Serialized roots remain evidence, never authority.

StageWitness payload must not own the native token (avoid cycles); it owns only
the gas capability and immutable proof. A stale/foreign/retried/failed gas attempt
or mutation invalidates private stage publication. Stage1 then advances only the
native private frame; both accepted owners remain untouched.

4. Final common publication

Gas prepare_commit invalidates its CandidateBinding, so the last stage witness
cannot authorize final publication. The bridge prepares an actual gas
PreparedCommit and native sealed outer token, then attaches a distinct final
witness that preflights gas.can_publish(prepared). Both tokens and exact rollback
scope live in one move-only pair, with no raw native accepted token escaping.
The pair can join the coordinator's all-owner preflight. Publication then uses
only already-qualified noexcept native/gas/arrival/Hall/source swaps; all
hashing, strings and allocation precede the first accepted swap.

Common checkpoint/history must bind both accepted owner roots and actual stage
proofs. A native-only checkpoint does not assert whole-system closure. Restoring
an owner for inspection is distinct from restoring a coupled continuation;
continued coupled operation requires the verified common owner manifest.

5. Required qualification before changing the strict gate

Real eventful and no-event two-stage controls; poisoned/abandoned trials before
and after gas.take; tampered actual reference/stock/debit/charge proof operands;
foreign native/gas owners; same-digest retries and mutation revisions; moved and
destroyed capabilities; allocation failure sweeps before all publication steps;
no allocations/GPU launches during can_publish/try_publish; refused paths leave
accepted counts, gas stock, RNG, source heat and clocks unchanged; common
checkpoint/restart reproduces exact histories. Initial implementation CPU only,
explicitly refuses unqualified device path. Full network/material/field physics
qualification remains separate from exact bookkeeping.

Numerical defects are explicit ledgers, not physical stores. Report raw stored
energy/momentum balances separately from the accounted residual after the
existing guarded per-event floating-point defect and independently derived
reference-operand conversion. Exact zero of that accounted residual establishes
consistent bookkeeping; it does not claim raw physical energy sums are exactly
zero or validate the collision model itself.
