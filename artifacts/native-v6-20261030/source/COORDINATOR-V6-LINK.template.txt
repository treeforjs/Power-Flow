C. Common predicate for steps whose source digest changes (births)
 V3 accepts_closed_step (common_commit_contract.hpp, unchanged) refuses a candidate whose source seal differs
 from the accepted one. v6 provides, in source/adapters/common_commit_v6.hpp (include with
 -I pic-water-common-commit-v3-20261030/source; no V3/V4 file is edited):
   bool accepts_closed_or_birth_step(const ExpectedStep& e, const ObservedOwners& current,
       const ProposedOwners& candidate, const FullTimeStepFlows* flows, const ArrivalEvidence& arrival) noexcept
 accepted iff
   (1) candidate.after.source is a digest and equals candidate.after.native.source_sha256;
   (2) if the sealed native step has a birth receipt R (flows->births):
         R.accepted_step == e.before.accepted_step, R.source_before == e.before.source_sha256,
         R.source_after == candidate.after.native.source_sha256, R.next_id_after - R.base == |R.entries|,
         and the arrival evidence of the step (staged token, plan digest, B_s, birth count) equals R's
       otherwise the source seal is unchanged and no arrival step is staged;
   (3) every V3 accepts_closed_step condition holds with the bound source transition substituted (the
       candidate's source seal replaced by the accepted one).
 Exceptions return false. Controls in tests/test_v6_flows.cpp (predicate section): V3 refuses the birth step,
 v6 accepts it, and refuses a foreign arrival token, a missing birth receipt, an unbound source seal and a
 receipt whose transition the candidate does not show.

D. Hall side (separate Hall version): what native v6 admits
 The flows record (API-006.txt section 4, schema canonical-full-time-total-field-motion-v3-flows-binary):
 newborn carriers (trial.birth_flights(): native ID, tau, end - tau) move only over [tau, end] from their
 birth position (possibly on the emitting foil face, leaving it); first-hit truncation at fraction f of the
 carrier's straight segment D with the sealed kinetic policy (kinetic_boundary.cpp first_kinetic_hit
 arithmetic, later exact tie wins, fraction 1 is a hit), hit point start + f D with the plane coordinate,
 flight F f, remaining F (1 - f) discarded; one FullTimeSinkRecord per removed carrier; all carriers of a
 logical packet are removed together; current/charge deposits over the truncated paths; kinetic budget over
 survivors (endpoint u) and sinks (incident u). Native recomputes the record digest, the first hit, the hit
 point, the truncated path and the budget, and refuses any inconsistency (typed FullTimeFlowRefusal).
