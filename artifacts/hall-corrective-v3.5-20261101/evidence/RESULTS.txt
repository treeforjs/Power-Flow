4. Decisions taken (engineering)
 - Version split: v3.5 = restore_as_genesis (the coupled-run unblocker), sealed first; GPU speed -> v3.6; integration
   items -> v3.7.
 - v3.3 checkpoints accepted for the genesis only (verification forms reproduced: v3.3 configuration composition and
   v3.3 merkle form over the same device leaves; the v3.3 host ledger record); plain restore keeps v3.4/v3.5 only.
 - divB gross ledger: kept from v3.4/v3.5 checkpoints, zero from a v3.3 checkpoint (no value recorded; zero is the
   smaller floor, i.e. the stricter check).
 - The recorded configuration is identified among candidate operand sets (declaration: the restoring one, none, or
   GenesisTransfer::recorded_declaration; limits: the restoring ones, CarrierLimits{}, the checkpoint's record (v3.5) or
   GenesisTransfer::recorded_limits); GenesisTransfer gains the two optional recorded operands for checkpoints that do not
   record them.
 - Heat transfer through the sealed Coupler's own checkpoint reader (an in-memory file with this Model's slice
   signatures, revision 0, appended zero inventories); the checkpoint's slices are first loaded under the recorded
   declaration, so the sealed signature check covers the recorded slice definitions.
 - Checks run inside the restoring constructor (hook after the upload, before the census check and admission) so that the
   order a-f of the request holds (a flipped word is reported by the seal, not by the admission).
 - Host Owner genesis: the recorded configuration uses the restoring Model's dt_max, solve backend and motion forms (the
   host checkpoint does not record them; host plain restore requires them equal as before).
 - Vacuum state: free charge net and gross zero at every node, no bank residue, empty kinetic ledgers; a census of
   co-located neutral pairs is admitted at the genesis (restored-form census check), and the rebased free-charge
   ledger is zero until the first coupled step replaces it from the carriers (1.5 shows the states then coincide).
 - Host checkpoint key "genesis_provenance" always written (null for non-genesis owners).
