The base GPU/sanitizer qualification was pending at capture. No deployed binding

coverage/target-energy policy. No reaction tables, estimates or rates are added.

Configuration:
  FullTimeWaterScopeMode::legacy (default) keeps the previous encounter behavior.
  minimum_water requires an explicit canonical contract and its SHA256. The
  helper full_time_minimum_water_scope_contract(base, options) produces that
  contract from the actual blob, registry and base chemistry configuration.
  Call it before setting the mode/contract fields. The base digest excludes the
  scope policy itself; the final configuration digest includes base + mode +
  contract digest, avoiding circular hashing. Disabled chemistry cannot carry
  any scope request. A changed seed, grid, policy or blob invalidates the contract.

Admission:
  Every host chemistry exposure builds a census from the private native frame,
  actual carrier IDs/weights, packet species and setup.grid.locate. It runs
  before existing projectile and target filtering. Unmapped resident native
  species and invalid vacuum cells refuse. There is no out-of-scope exemption.
  Native row count, actual particle root, snapshot/history/clock/field identity,
  stage sequence, duration, registry and collision geometry enter the binding.
  The authentic census binding is retained locally, then verified by the shared
  minimum-scope component before MCC, resolution, debit or RNG publication.
  Missing required groups and wholly unbounded groups with positive same-cell
  species refuse. Zero/absent or separate-cell populations are inactive for
  this stage only. The gate adds the missing e+OH, e+O and e+H2 pairs to every
  existing table pair; it does not assert a complete chemical network.
  Existing regional bounds, unknown-region and target-energy guards still run.

Both collision exposures use their own actual private frame, including the
post-motion frame for stage2. An outer-step failure discards its earlier private
stage. Accepted scope census/binding and a rolling scope-history digest enter
chemistry state and a canonical stage row; they survive the new v8.4 checkpoint
configuration and chemistry codec. Historical v8.3 checkpoint schemas are not
silently accepted as this new identity. Existing legacy modes inside v8.4 also
have a new source/schema identity, without changed chemistry rates.

GPU limitation:
  minimum_water with device or device_verified chemistry or native-lane execution
  throws a typed scope
  refusal before device dispatch and before generic host fallback. No GPU
  all-species census is implemented or qualified by this work.

The controls use manufactured native carriers, synthetic fields and diagnostic
rate policy where explicitly selected. Passing this minimum guard never implies
network_complete, physical_model_validated, production qualification, measured
EEDF, or whole-system energy closure. No coupled physical run is authorized by
this component work.
