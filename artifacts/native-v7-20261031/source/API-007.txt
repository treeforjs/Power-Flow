0. Encoding conventions (native v5 canonical primitives)
 u64 = 8 bytes little-endian; f64 = IEEE-754 binary64 bit pattern as u64 (-0.0 != +0.0); text = u64 byte
 length then the bytes; SHA-256 per FIPS 180-4; hex digests lower case. RN = round to nearest, ties to even.

1. Definitions
1.1 Exact sums (a)
 KE(m, u) := pic_kinetic_energy_J = RN(RN(m * n) / RN(g + 1)), n = RN(RN(RN(u0 u0) + RN(u1 u1)) + RN(u2 u2)),
   g = RN(sqrt(RN(1 + RN(n / C2)))), C2 = RN(299792458^2) = 89875517873681760 (no contraction; bitwise equal to
   the sealed native.o function, verified in tests).
 d_i := RN(KE(m_i, u_i_end) - KE(m_i, u_i_start)) for every census carrier i (m_i, w_i, u_i_start: the census
   carrier; u_i_end: endpoint proper velocity of a survivor, incident proper velocity of a sink record).
 kinetic_change_J := RN( SUM_i w_i x d_i ), products and sum exact (real arithmetic); an exactly zero sum is
   +0.0. Independent of order and of any partition of the terms.
 field_work_J := RN( dt x RN( SUM_e E_e x J_e ) ), E = midpoint total field edge values, J = current_A_m;
   products and sum exact.
 work_defect_J := RN(kinetic_change_J - field_work_J) (unchanged from v6). Guard: amendment A1 below
   (the v6 net form |defect| <= 1e-20 + 1e-10 (|K| + |W|) is replaced).
 A nonfinite factor, a rounded sum outside the binary64 range, or a census carrier without an end state is a
   producer refusal (status bits, section 2) and a native refusal.
 Old (v6): K = double(long double sequential sum over the census of (long double)w_i x d_i) and
   W = dt x double(long double sequential sum of (long double)E_e x J_e) (x87, 64-bit significand, rounding at
   every step). Native v7 recomputes K in the new form and requires bitwise equality.
 Amendment A1 (2026-10-31): work tolerance motion-work-gross-v1
   Specification: hall-corrective-v3.2-20261031/MOTION-WORK-GROSS-V1.txt (Hall reference
   source/motion_work_gross_v1.hpp; native implementation pf_v7::work_* in forms/, bitwise equal, tests).
   tol = RN(RN(RN(1e-20 + RN(1e-10 x RN(G_K + G_W))) + RN(2^-47 x C_K)) + RN(RN(8e-18 x E^) x Q)), admitted iff
   every sum status is 0, defect and tol are finite and |defect| <= tol. Over the charged census carriers
   (q_i != 0): G_K = RN(SUM w_i |d_i|), C_K = RN(SUM w_i K0_i + w_i RN(K0_i + d_i)), Q = RN(SUM |q_i| w_i),
   K0_i = KE(m_i, u_start_i); field: G_W = RN(dt x RN(SUM_e |E_e| |J_e|)), E^ = max |E_e| over the edges with an
   endpoint node on an edge carrying J != 0 (0 when none), Hall axial mesh edge numbering. Exact sums, exact
   maximum, fixed evaluation order.
   Reason: the net form 1e-20 + 1e-10 (|K| + |W|) scales with the NET exchange, which passes through zero in
   dense plasma, while the defect comes from per-carrier rounding of the kinetic values and from the work-path
   fixed point (|D_(k+1) - D_k| <= 1e-18 m), neither of which the exact sums remove: Hall v3.2 dense blobs were
   refused at omega_p t ~ 2.7-3.2 under the net form and run 400 steps under the gross form (max |defect|/tol
   9.5e-4). The gross form refuses every inconsistency the net form refused that is not a rounding artefact.
   Admission inputs (native holds no field): the record carries spans trial_E (edge values), trial_B (face
   values) and current_A_m (J); native requires trial_field_sha256 = SHA256(text "total-midpoint-E-B-binary64-v1",
   u64 |E|, E, u64 |B|, B) (Hall total_field_sha256) and current_A_m_sha256 = motion-array-binary64-v1(J); the
   mesh (n = nx = ny, nz) is the unique solution of |E| = 2n(n+1)(nz+1) + (n+1)^2 nz, |B| = 2n(n+1)nz + n^2(nz+1)
   (so it is bound by trial_field_sha256). These spans are not hashed into the record digest (1.2 unchanged).
   With E and J in hand native also recomputes field_work_J and requires bitwise equality (as for K).
 Implementation (any exact method gives the same bits): superaccumulator of 134 radix-2^32 digits held in
   int64, value = SUM_k digit_k 2^(32k - 2148); a product of two binary64 values (53-bit significands, LSB
   exponents >= -1074) is added exactly as five 32-bit chunks; carries are propagated once; the conversion
   rounds once (guard + sticky, ties to even, gradual underflow, overflow -> refusal). Interchange form of a
   partial sum (ranks/blocks): the normalised digits (0..132 in [0, 2^32), digit 133 signed); merging is
   digit-wise addition followed by normalisation. Capacity: < 2^31 terms per device launch, unbounded on the
   host (normalisation every 2^30 terms).

1.2 Block lists and the motion record digest (b)
 Section block list over n canonical records of fixed size R, in canonical order (ascending native ID):
   chunk j (records [32j, min(32j+32, n)), m_j records):
     c_j = SHA256(text "<tag>/chunk", u64 j, u64 m_j, m_j x R record bytes)
   leaf k (records [1024k, min(1024k+1024, n)), n_k records, q_k = ceil(n_k/32) chunks):
     l_k = SHA256(text "<tag>/block", u64 k, u64 n_k, u64 q_k, c_(32k) .. c_(32k+q_k-1) as 32 raw bytes each)
   tree: native v5 rule over l_0 .. l_(L-1): node(a, b) = SHA256(text "native-v5/merkle-node", a, b), pairs left
     to right, an odd last node carried up; no leaves: SHA256(text "native-v5/merkle-empty")
   root = SHA256(text "<tag>/root", u64 1024, u64 n, u64 L, tree raw)    (native v5 merkle_root layout)
 Leaves hold 1024 consecutive records (positional, not native-ID ranges: the leaf count is ceil(n/1024)
 whatever the ID spacing); the 32-record chunks keep the device latency of one leaf at ~60 compressions.
 Sections, tags and records (bytes, packed little-endian):
   native-v7/motion-endpoints  80  u64 id, 3 f64 position, 3 f64 proper velocity, f64 charge, mass, weight
                                   (= GapParticle; survivors in ascending ID)
   native-v7/motion-paths      64  u64 id, 3 f64 field start, 3 f64 field displacement, f64 flight
                                   (= FullTimeMotionPath; every census carrier)
   native-v7/motion-sinks     136  u64 id, u64 kind, u64 surface, u64 axis, f64 plane, f64 fraction, 3 f64 segment,
                                   3 f64 hit point, 3 f64 incident proper velocity, f64 flight, f64 discarded flight
   native-v7/motion-births     24  u64 id, f64 birth time, f64 flight (newborns of the trial)
   native-v7/census-carriers   96  u64 id, 3 f64 position, 3 f64 proper velocity, f64 charge, mass, weight,
                                   u64 packet key, u64 state index (section 1.3)
 Motion record v7 digest (record_sha256 = transport_trial_sha256), SHA-256 of:
   text "canonical-full-time-total-field-motion-v7-merkle"
   text "binding", text "full_time_position_and_proper_velocity", u64 accepted_step, u64 staged_arena_revision,
     u64 trial_stage, f64 begin_s, f64 end_s, f64 dt_s, text staged_arena_sha256, text trial_field_sha256,
     text mesh_sha256, text material_sha256, text species_sha256, text common_clock_sha256,
     text kinetic_policy_sha256
   text "budget", 7 f64 (kinetic_change_J, field_work_J, work_defect_J, continuity_C, plasma_dt, maximum_gyro,
     maximum_displacement_cells)
   text "census_sha256", text census v2 digest (1.3)
   text "coverage", text "all_native_carriers_births_and_first_hit_sinks"
   text "current_A_m_sha256", text; text "endpoint_charge_C_sha256", text; text "initial_charge_C_sha256", text
     (motion-array-binary64-v1 digests, unchanged)
   text "kinetic_policy", text "native-finite-target-kinetic-policy-v1", 12 f64 (width, gap, short_z, feed_z,
     lower l/r/b/t, upper l/r/b/t), text "lower foil x span and inner y gap only", text "absorbing escape",
     text "axial escape", text "x y lower upper axial; later exact tie wins"
   text "native_DKD_called", u64 0; text "native_Poisson_called", u64 0
   text "native_to_field_m", 3 f64
   text "neutral_motion_owner", text "same_full_time_q0_drift"
   text "neutral_stream_dt_max_s", f64 (1.4)
   text "motion_owner", text "ordinary_total_field"
   text "endpoints", u64 n, text endpoints root; text "paths", u64 n, text paths root;
   text "sinks", u64 n, text sinks root; text "births", u64 n, text births root
 The header is O(1) host work; the per-carrier hashing is the four section block lists (device).
 One schema for every step (empty sink/birth sections are allowed). Old (v6): the binary v3 record
 (streaming SHA-256 over all fields and arrays, two schemas) or the v2 JSON seal; neither is accepted by v7.

1.3 Census v2 (c)
 Canonical order: ascending native ID (stable sort by the u64 ID when a producer holds another order).
 Per carrier: packet key := smallest native ID among the carriers of its logical packet; state index := rank
   of the packet's species state in the state table (native's registered states, ascending byte order).
 Canonical check of record i (first failing record wins; codes pf7::CensusCode):
   1 id_zero; 2 not_ascending (id_i <= id_(i-1): unsorted or duplicated); 3 key_invalid (key 0 or key > id);
   7 state_range (state >= S); for key != id: 4 key_absent (no census record with id == key),
   5 key_not_first (that record's key != its id), 6 divergent (position, proper velocity, charge, mass or
   state differs bitwise from the key record: the duplicate/divergent-packet check of Hall's census admission).
 states_sha256 = SHA256(text "canonical-motion-census-v2/states", u64 S, S x text name)
 census_sha256 = SHA256(text "canonical-motion-census-v2-merkle", u64 N, text states_sha256,
   text root of the native-v7/census-carriers block list)
 Packet ID texts are not part of the census (they are bound by native's accepted-state digest); a producer
 needs them only for its own sink/newborn bookkeeping (PrivateTransportTrial::carrier_packet).
 Old (v6): canonical-motion-census-v1 = streaming SHA-256 over (text packet ID, text state, carrier) per
 carrier in ascending ID.

1.4 Resident-neutral stream bound (configuration)
 pf_v7::neutral_stream / pf7::neutral_stream: port of the sealed prepare_neutral_stream (Hall 8dddec0
 kinetic_boundary.cpp:57) with the literal dt <= 1e-14 replaced by dt <= neutral_stream_dt_max_s. Arithmetic,
 check order and refusal texts are the sealed ones (bitwise equal at the default, tests). The real limit for
 neutrals stays the 0.2-cell displacement guard (budget[6]).
 Native configuration FullTimeConfiguration::motion.neutral_stream_dt_max_s (default 1e-14; finite, > 0):
 bound into the native configuration identity only when it differs from 1e-14 (default identities = v6),
 carried in every v7 record header (must equal the configured value) and in the motion audit; native refuses
 a step with dt above it when the census holds a resident (non-newborn) neutral carrier.
