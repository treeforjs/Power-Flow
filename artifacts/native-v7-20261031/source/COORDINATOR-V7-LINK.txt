B. Linking v7 (coordinator v7)
 1. N = R / 'pic-reaction-transactions-20261029/native-full-time-candidate007'; include -I N/source/include
    -I N/forms/include (-I N/source/adapters for the adapters); link N/build/libpic_native_v7.a and -lcrypto. No
    Hall object is needed by the core; the transitional adapter compiles against the Hall motion_receipt.hpp in use.
 2. Configuration: FullTimeConfiguration::motion.neutral_stream_dt_max_s (default 1e-14; finite, > 0). Pass the
    same value to the Hall motion provider (HALL-LINK.txt item 4); native refuses a record whose
    neutral_stream_dt_max_s differs from it, and a step with dt above it when the census holds a resident neutral.
    It is in the configuration identity only when it differs from 1e-14 and is saved in the checkpoint
    configuration (key neutral_stream_dt_max_s, present only when non-default). The native core has no other
    1e-14 literal; the V3 common-commit contract (common_commit_contract.hpp:82) still has one (coordinator side).
 3. Census per trial: trial.census_v7() (carriers span, packet_keys, state_indices, states, states_sha256,
    carriers_root, sha256), computed once per trial; trial.census_sha256() = census_v7().sha256. Hand the arrays to
    the Hall v3.2 device census (HALL-LINK.txt item 1); trial.carrier_packet(native_id) gives (packet ID, state) for
    sink/newborn bookkeeping. trial.native_census(cap) (texts) is unchanged.
 4. Motion admission (per accepted iterate):
      FullTimeMotionRecordV7 x;   // header fields, budget[7], census_sha256 = trial.census_sha256(),
                                  // spans endpoints/paths/sinks/births, neutral_stream_dt_max_s,
                                  // A1 inputs: trial_E (edges), trial_B (faces), current_A_m (J)
      x.record_sha256 = <Hall v3.2 record digest>  (or full_time_motion_record_v7_sha256(x));
      binding.transport_trial_sha256 = x.record_sha256;
      trial.prepare_total_field_motion(binding, bind_total_field_motion_v7(x, storage));
    trial_E/trial_B must be the arrays of the record's trial_field_sha256 (total-midpoint-E-B-binary64-v1) and
    current_A_m those of current_A_m_sha256 (motion-array-binary64-v1); the spans and storage must outlive the call.
    For a Hall that does not emit the v7 forms (v2/v3.x receipts):
      auto m = v7_adapter::from_hall_receipt(receipt, trial, E_mid, B_mid, neutral_bound);
      binding.transport_trial_sha256 = m->record.record_sha256;
      trial.prepare_total_field_motion(binding, v7_adapter::admit(m));
    (O(carriers) host work in the adapter: K, W, scales, section roots.)
    The "exposures transport trial == motion record" check of the coordinator compares the v7 record digest.
 5. Births, sinks, restart and the common predicate: unchanged from COORDINATOR-V6-LINK.txt sections B.4-B.6 and
    C (common_commit_v6.hpp, accepts_closed_or_birth_step); the motion record of a births trial must state the
    newborn flights (births section) as in v6.
