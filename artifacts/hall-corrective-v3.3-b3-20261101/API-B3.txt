Hall v3.3 host B3 successor API

Same namespace hall_corrective_v3; mutually exclusive predecessor/successor
headers/objects in one executable. CarrierPath now aliases the identical native
FullTimeMotionPath type, avoiding distinct-struct pointer aliasing. Serialized
default bytes are unchanged; consumers must rebuild against this header.

MotionForms.native_v81_bridges=true explicitly opts in and enters model identity;
it requires native_v7. StepInputs.matching_births points to the authentic live
PreparedBirths. Caller must retain native outer/scope capability lifetime.
prepare_closed_proposal requires CpuMotionProvider for this option; resident
proposal refuses any matching_births input. No implicit GPU fallback.

MotionAssembly::apply_matching_births(receipt, context, actual_census, births, E)
is the host completion path: validates actual births/step/census/foil geometry,
deposits extra J once, moves initial charge to the source face, rechecks current/
work guards and seals native v8.1 forms. Reapplying refuses. Actual field face
and outward phase determine bank origin; callers supply no electrode index.

MotionReceipt exposes bridges(), extra_current_A_m(), bridge_work_J() and
extra_work_J(). Ordinary kinetic work is total field work minus extra work.
StepEnergy.birth_supplied_J is matching-plane birth K minus bridge field work.
The separate electron work-function reservoir is not native species reference.

NativeMotionRecordV81 is a borrowed view by default; it must not outlive the
receipt/field arrays. retain=true owns every array. matching_motion_admission
always uses retained storage, so the admission survives producer destruction.
The scalar record hash is native-owned; no private hash grammar is duplicated.

Before common publication compare each genuine source SurfaceTransfer matching
work with its actual final-midpoint bridge_work_J entry using the qualified work
bound. Accepted-start source field may disagree with Hall final midpoint: then
transactional source/field iteration or a separately qualified split assessment
is required. Do not subtract the discrepancy from electrode heat.
