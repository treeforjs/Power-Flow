# Explicit dynamic-loss H2 CDF table and shared kernel

This isolated successor adds an explicit table descriptor and shared CPU/GPU event path for the qualified H2 b3Sigma source-CDF diagnostic. It preserves all six historical process kinds and fixed-loss behavior under the corrected RNG layout 2. No native runtime or production binding is changed here.

The binary format is PFCHEMV3 version 2. Existing version 1 blobs remain readable; old version 1 loaders reject version 2. New process kind 32 is DISSOC_CDF. ProcessRec remains 512bytes; its formerly reserved pad0 word is now a named cdf_index used only by kind 32. Version1/non-CDF records must retain zero in that slot. The new CdfRec is 256bytes, schema 1/model 1, with dedicated cdf_desc, cdf_quantile and cdf_fragment_eV sections. TableView has a new internal host/device ABI and therefore requires a fresh native compilation/identity; compatibility is not inferred from unchanged ProcessRec size.

The descriptor binds projectile e, target H2(v=0), ground H products, exact source/model identities, the published quantile interval 0.001–0.999, omitted probability 0.002, rate window 4.5–150eV, finite-target event-support threshold 7.164126535758105eV, conditional normalization and RNG layout 2/word 96. The descriptor loader requires an externally pinned blob SHA, validates structure/state/units-as-schema/monotonic values/provenance and rejects unknown models. The temporary legacy-builder blob is never published or executed; its new record is replaced by the explicit kind 32 descriptor before testing. Dynamic loss is Q+twice sampled per-H pair-rest energy. Ordinary fixed-loss fields are not used to conceal the distribution.

The physical model is the separately qualified h2-b3sigma-cdf-diagnostic-v1-20261101: primary MCCC integral plus E. Sartori's Table I Franck–Condon/delta KER approximation. Isotropic scattered-electron and fragment angles are assumed. The omitted source tails are neither extrapolated nor known zero. Integral rates remain positive below the retained event-support threshold, but that interval is explicitly UNRESOLVED. An unsupported selected CDF event returns carrier status 8 and refuses the stage; it cannot enter the historical ordinary-kinematic-null path. Exact zero internal energy is required for ground H products.

Incomplete encounter groups remain refused. All new H2 group regions remain unbounded under the strict policy, with no unbounded admissions. Missing elastic/momentum transfer, rotational/vibrational/electronic excitation, other neutral dissociation, ionization, dissociative attachment and other radiative energy-loss processes remain explicit. Existing OH omissions and absent O/ion/recombination groups are unchanged. No populated complete-water-network qualification is claimed.
